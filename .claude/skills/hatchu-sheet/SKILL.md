# 発注書シート作成 + メール下書き

確認質問はしない。不明点は仮定して進め、最後の返信に1行で書く。返信は簡潔に(リンクと要点のみ)。
検索や全体読み込みはしない。下記のIDを直接使う。

## 入力の読み取り
- 注文日 = 今日。希望着日 = 「〇/〇午前着」。届先名 = 住所の施設名(例: 浜屋百貨店)。
- 数量: 「計Nケース」を品目数で割る。品目1つにつき1ケースが基本。

## 1. シート作成(Google Drive / Sheets)
- 原本: `1yOTJbrPg5wjNbIixxEQp5wBlhUNw6v-e99eqcC1b5OU`
- 保存先フォルダ(発注書): `1aRSB_u7n6icUUxBQKuqcdK5-_nC6vqj0`
- `copy_file`(fileId, parentId, title=`YYYY-MM-DD_発注書_OKBAGEL_ケース用_<届先略称>`)。引数は `title`(`name` は不可)。
- タブ名は `注文書2026.8月より価格変更`。`update_values` で次を入力(数式セルは触らない):
  - `G3` 注文日(`YYYY/MM/DD`)
  - `D9` 届先名(`出店先一覧` B列と一致させる)
  - `E15:E30` 数量。行は品目順で、15 プレーン / 16 全粒粉 / 17 マンハッタン / 18 ブルーベリー / 19 バタースコッチ / 20 ダージリンホワイト / 21 抹茶ホワイト / 22 クランベリーマカダミア / 23 チーズ / 24 メープルウォルナッツ / 25 ミルキーシュガー / 26 ミルキーチョコ / 27 アズーリ / 28 エブリシング / 29 シナモンシュガー / 30 大学芋
- `update_spreadsheet` でタブ名を `注文書` に変更(sheetId `1172011027`、`updateSheetProperties` の `fields: "title"`)。
- 自動計算: `D8` 希望着日は注文日+1日の午前。それ以外の日付なら `D8` に文字列で上書きする。`D10` 住所は `出店先一覧` から引く。金額と合計も数式。
- 届先が `出店先一覧`(非表示タブ、B=届先名、C=住所)に無い場合は、その表の末尾に行を追加する。住所は依頼文の住所をそのまま使う。
- 確認は `get_values` で `注文書!B3:H33` を1回読む。
