# 出店申込書の自動入力

情報源は `okbagel-profile.md`(同じフォルダ)。申込書の項目をこれと照合して埋める。
プロフィールに無い事実は推測で作らない。

## 手順
1. 申込書を読む(ファイル/リンク/貼り付け文)。形式は問わない。項目名の表記ゆれ(例: 代表者/申込者/担当者)は意味で対応づける。
2. `okbagel-profile.md` を読み、各項目を次のどれかに分類する:
   - 確定: プロフィールに値がある → そのまま入力
   - 催事ごと: 期間・希望区画・品目・電源要否など → 依頼文や過去の申込(「過去の申込履歴」)から埋める。無ければ未入力
   - 不明: プロフィールに無い → 空欄のまま
3. 入力方法(形式別):
   - Googleスプレッドシート/ドキュメント: `copy_file` で複製してから `update_values` 等で入力(原本は触らない)
   - Excel/Word/PDF: `xlsx` / `docx` / `pdf` スキルで入力済みファイルを別名保存
   - Webフォーム: 入力内容を項目名つきの一覧にして返す
4. 不明項目はまとめて1回だけ質問する(項目ごとに何度も聞かない)。

## 学習(重要)
- ユーザーが不明項目に答えたら、その場で `okbagel-profile.md` の該当欄に追記する(「確定情報」へ。催事ごとの情報は「過去の申込履歴」へ)。
- 申込書に新しい種類の項目が出たら、「項目名の表記ゆれ」表に追記する。
- 申込が完了したら、「過去の申込履歴」に1行追加する(催事名/主催/期間/出店区分/備考)。
- 追記したらコミットする。

## 返信フォーマット
入力済みファイルのリンク、未入力項目(あれば)、追記した学習内容を各1行で。
