# 催事・POPUP市場調査：国内 製菓・製パン編

調査日: 2026年10月19日
対象: 日本国内の洋菓子・和菓子・チョコレート・パンの、百貨店催事／駅ナカ・商業施設のPOPUP／パンイベント
関連: [催事・POPUPイベント 市場調査（全体版）](./popup-saiji-market-research.md)

---

## 1. サマリー

- **菓子市場は5年連続で過去最高。** 2025年の菓子小売金額は推定 **4兆996億円（+5.7%）** で、初めて4兆円を超えた。チョコレートは7,105億円（+12.6%）。ただし伸びの中心は**値上げ**で、数量は伸び悩んでいる。
- **パンは「コメ高」の追い風。** 2人以上世帯のパン消費額は1日114円で、コロナ前より約1割多い（調理パンは約3割増）。パン屋の倒産は2025年1〜10月で15件と前年から約4割減り、約7割が黒字。
- **百貨店の食品催事は国内客が支えている。** 訪日客の買い物が落ち込むなか、バレンタイン催事・物産展・パン催事は堅調。2025年のバレンタインは高島屋大阪店の店頭売上が+14%、あべのハルカス近鉄本店（催事場）が+10%。
- **催事の勝ちパターンは「限定品・実演・イートイン・何度も来たくなる仕掛け」。** 北海道展ではチラシ掲載商品の約8割が限定品。1〜2日ごとにメニューを替えるパフェなど、何度も来てもらう企画が広がっている。
- **最大の課題は原材料高。** カカオはピークから下がったものの、数年前の約2倍。バター（200g）は2020年比で約4割高く、乳業大手は2026年夏に追加値上げ。卵・油脂も高値が続く。値上げの「納得感」と、1個から買える商品の設計が重要。

## 3. 催事の種類ごとの動向

### 3-1. バレンタイン催事（百貨店最大のスイーツ催事）

- 代表的な催事：伊勢丹新宿店「サロン・デュ・ショコラ」、高島屋「アムール・デュ・ショコラ」、阪急うめだ本店「バレンタインチョコレート博覧会」、JR名古屋タカシマヤ「アムール・デュ・ショコラ」など。**1日平均1億円以上を売る催事もある**と報じられている。
- **2025年の結果（関西）:** 高島屋大阪店の店頭売上は+14%（EC込みで+6%）、あべのハルカス近鉄本店の催事場は+10%。阪急うめだ本店の売上目標は31億円。
  - 売れ筋：**関西の洋菓子店**（ポワール、マールブランシュ、カカオティエ ゴカンが上位）、焼菓子、イートイン（パフェ・かき氷）
  - 苦戦：値上がりした**輸入ブランド**
- **2026年も堅調。** 東京地区の1月の食品売上は+4.1%で、バレンタイン催事が寄与。チョコ1粒の平均価格は436円（+4.3%）と2年連続で過去最高。上げ幅は国内ブランド+2.0%に対し、輸入ブランド+7.2%。
- **流れは「脱チョコ頼み」。** カカオ高を受けて、焼菓子・パフェ・かき氷などスイーツ全般を扱う催事に変わってきている。阪急は「1個から買える」商品を増やした。

**示唆:** 国内の中堅・地方の洋菓子店でも上位に入れる場になっている。チョコ以外の焼菓子やイートイン商品を軸に出店する余地が大きい。

### 3-2. 物産展（北海道展など）のスイーツ・パン

- 物産展は百貨店で最も客を呼べる催事の一つ。高島屋主力店の「大北海道展」は2024年に売上が約1割伸びた。
- 京王百貨店新宿店の2025年春の大北海道展では、**会場実演スイーツが過去最多の80種**、パフェ・ソフトクリーム・ジェラートなどの冷たいスイーツが60種以上。セイコーマートのクロワッサンなど**パンの初出店**もあった。
- 東武百貨店池袋店では、**チラシ掲載商品の約8割が限定品**。
- 定番の強いブランド（ロイズ、六花亭のマルセイバターサンドなど）と、初出店・限定品・実演を組み合わせて集客している。

**示唆:** 地方の菓子・パン事業者は「その催事だけの限定品」と「実演・できたて」を用意することが出店の前提になる。

### 3-3. パン催事・パンイベント

- **百貨店のパン催事は定例化。** 神戸阪急「パンフェスタ」（2026年9〜10月に第7回、約30店）、阪急うめだ本店「阪急パンフェア」、阪神梅田本店のシュトーレン催事（50種以上、12月）など。
- **屋外・大型のパンイベントも多い。** 「パンのフェス」（横浜赤レンガ、幕張など）、世田谷パン祭り（約140店・2日で約5万人、2018年）、あまがさきパンフェスタ、てくてくパンまつり（神戸、約50店）など。
- 季節ごとの軸：**秋のパン催事、12月のシュトーレン、春のパンまつり**。
- **教訓（高級食パン）:** 1本1,000円を超える高級食パンは2018年ごろに急増し、その後閉店が続いた（ある大手チェーンは140店→約40店）。一つの商品だけのブームは長続きしないため、催事でも**品揃えの幅と、別の価値づけ**が必要。

### 3-4. 駅ナカ・商業施設のPOPUP

- エキュート・グランスタ（JR東日本）では、期間限定フェア（例：カスタードを使ったシュークリーム・パンなど23品）や、**期間限定のベーカリー出店**（ピーターパン）を実施。地方駅の催事会場への出張販売もある。
- JR西日本グループは、企画から仕入・販売までまとめて支援する駅ナカ催事の仕組みを用意している。
- 商業施設はポップアップ前提の区画づくりを進めていて、入れ替えやすい食品物販は相性がよい。

**示唆:** 駅ナカは**手土産・通勤客向けの小さく持ち帰りやすい商品**が向く。百貨店より短い期間・小さい区画で試しやすい。

## 4. 商品・トレンド

| 傾向 | 内容 |
|---|---|
| 食感で選ばれる | 「温×冷」「サク×とろ」など、食感や温度の組み合わせを打ち出したスイーツ。2025年の関西バレンタインでも食感を軸に企画 |
| 冷たいスイーツ・イートイン | パフェ、かき氷、ソフトクリーム、ジェラート。催事でも成績が良い |
| 韓国発の冷菓 | ヨアジョン（韓国発のフローズンヨーグルト）、クラッキングアサイーなどが2026年の注目候補 |
| もちもち・新食感 | マンゴーサゴ、白玉入りのかき氷など |
| 素材重視・甘さ控えめ | 精製糖を減らし、素材そのものの甘みを好む傾向 |
| 1個売り・少量 | 値上げのなかで客単価を抑える工夫。阪急のバレンタインでも採用 |
| 調理パン・食事パン | コメ高でパン食が増え、調理パンの消費が約3割増 |
| 地域・ストーリー性 | 国産原料や地域の特色を打ち出した商品は高めの価格でも受け入れられやすい |

## 5. コスト環境（2025〜2026年）

| 原料 | 状況 |
|---|---|
| カカオ | 2025年1月に過去最高値（数年前の約4倍）。その後は下がったが、2025年12月時点でも数年前の約2倍。店頭価格に下落が表れるのは早くても2026年後半〜2027年以降との見方 |
| バター | 200gで613円（2025年12月、農林水産省調べ）。2020年比で約4割高い。乳業大手が2025年に3〜11%値上げし、2026年7〜8月にも追加値上げを予定 |
| 鶏卵・油脂 | 高値が続く |
| 人件費・エネルギー | 上昇が続く。パン屋の「三重苦」（原材料・人件費・エネルギー） |

**催事・POPUPへの影響:**
- 催事は場所代や売上の取り分が引かれるため、原材料高が利益を圧迫しやすい。**催事価格（限定品の価格）を店頭と分けて設計する**のが現実的。
- 輸入原料を多く使う商品は価格が上がって苦戦しやすい（2025年バレンタインの輸入ブランドの例）。

## 6. 出店の実務

### 6-1. 営業許可（食品衛生）
- **製造所で作った商品を包装して持ち込む**場合は、製造所が「菓子製造業」の許可を持っていれば、基本的に包装品として販売できる（自治体によって扱いが違う）。
- **会場で焼く・仕上げる（実演）**場合は、会場を管轄する保健所の許可や届出が別に必要になることが多い。
- 自治体によっては、一つの事業者の販売促進イベントは「催事」の扱いにならない場合があるため、**出店先の保健所と施設に必ず事前確認**する。
- 他の都道府県の催事に出る場合は、製造地と出店地の両方の保健所の扱いを確認する。

### 6-2. コスト構造（目安）
- 百貨店催事：売上の一定割合を百貨店に払う方式が中心。具体的な率は公開されておらず、催事担当への確認が必要。
- スペース仲介・商業施設：日額の賃料。2週間・場所代・機材・人件費込みで1日10万円前後の例（業種は問わない一般例）。
- 菓子・パン特有のコスト：冷蔵・冷凍設備、実演用の機材・電源、往復の配送（チルド・冷凍）、売れ残り（パンは廃棄リスクが大きい）。

### 6-3. 形態の選び方

| 目的 | 向いている場 | 商品の例 |
|---|---|---|
| 売上を最大化 | バレンタイン催事、物産展 | 限定の焼菓子詰め合わせ、実演スイーツ、イートイン |
| 新しい客・認知を得る | 駅ナカ期間限定、都市部の商業施設POPUP | 1個売り、手土産サイズ、SNS向けの見た目 |
| 地元以外での需要を確かめる | パンイベント、地方駅・SCの催事 | 看板商品と調理パン |
| 季節の需要をつかむ | 12月のシュトーレン催事、秋のパン催事 | 季節限定・予約商品 |

## 7. 機会とリスク

### 機会
1. **国内客を重視する百貨店の食品催事** — 訪日客頼みから国内回帰が進み、地方・中堅の洋菓子店やパン屋が上位に入る余地がある。
2. **バレンタインの「脱チョコ」** — 焼菓子・パフェ・かき氷など、チョコ専門店でない店も参加しやすくなった。
3. **パン食シフト** — コメ高を背景に調理パン・食事パンの需要が拡大。
4. **冷凍技術** — 冷凍パン・冷凍生地の市場拡大で、遠方の催事にも品質を保って出店しやすくなった。
5. **駅ナカ・商業施設の入れ替え区画** — 短期間・小さい区画で試せる場が増えている。

### リスク
1. **原材料高（カカオ・バター・卵）** と2026年夏の乳製品の追加値上げ。
2. **数量が伸びない** — 金額の伸びは値上げによるもので、客数・個数は横ばい。
3. **2026年11月からの免税方式の変更** — 訪日客が菓子を国内で食べると免税（返金）の対象外になる。訪日客向けの土産菓子の売上に影響する可能性。
4. **一過性ブーム** — 高級食パンのように、一つの商品に頼る出店は長続きしない。
5. **猛暑の長期化** — 生菓子・チョコの需要期が後ろにずれる（2025年度に実際に発生）。冷たいスイーツには追い風。
6. **パンの廃棄ロス** — 催事での作りすぎ・売れ残り。予約販売や時間帯別の製造で対策が必要。

---

## 8. 調査の限界

- 催事・POPUPでの菓子・パン売上だけを取り出した統計は見つからなかった。
- 百貨店に払う売上の取り分、パン催事の1日あたり売上の目安は公開情報で確認できなかった。
- 菓子市場の数値は全日本菓子協会の推定値で、日本食糧新聞の報道経由（協会の一次資料は未確認）。
- パン市場全体の最新実績（2024〜2025年度）は確認できず、2021年度の実績と2028年度の予測のみ。
- 2026年のトレンド予測は民間メディアの記事が中心。
- 出店の判断には、候補の百貨店・駅ナカ運営会社の催事担当、出店先の保健所への直接確認を推奨。
