# 海馬の決まり — Claude の仕様から導いた形（2026-10 の仕様）

**海馬は自動では読まれない。Claude が「目録 → 索引 → 本文」と手で引く保管庫。** だから設計の目的は「引きやすく・1回で読み切れ・圧縮の後も戻る」の3つ。

| Claude の仕様（2026-10） | 海馬への当てはめ |
|---|---|
| 自動で毎回読まれるのは `~/.claude/CLAUDE.md`・記憶の `MEMORY.md`（先頭 200 行／25KB）・スキルの説明だけ | 入口は [[目録]]。目録は薄く、全部はフォルダ索引で引く（二段） |
| 1回の `Read` は約 25k トークンで切れる（日本語で 60KB ほど） | **ハブ ≤ 15KB・本文 ≤ 60KB。** 超えたら日付の記録を `経緯_YYYY-MM.md` へ移す |
| 会話の圧縮の後に戻るのは直近に読んだ数ファイルだけ | 長い作業の決定は**その場で**海馬に書く。「あとで書く」は消える |
| 記憶は起動したフォルダごと | いつも `~/Documents/汎用` で始める |
| 「同じ間違いを2回したら CLAUDE.md、同じ始め方ならスキル、必ず毎回ならフック」 | 決まりは道具で測る（`リンク健診.py`） |

## 決まり
1. ハブ ≤ 15KB・本文 ≤ 60KB
2. 大きい資料は先頭に「一言で」と目次
3. 索引は二段: [[目録]] → フォルダ索引 → 本文。ノートを足したら索引に1行
4. 全ノートに frontmatter（name・tags・updated）
5. 記法は `[[ノート名]]`。測るのは grep ではなく道具
