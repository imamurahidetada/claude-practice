# 海馬 目録（入口）
Claude の長期記憶。会話の冒頭でまずここを読む。整理は「①移す ②索引 ③リンク」の三択で、削除はしない。
更新: 2026-10-23（導入）

## 常設ノート
- [やること](やること.md) — 本人に頼むことを1枚に集める。「1A 3済」形式で答える
- [保留中のタスク](保留中のタスク.md) — `[要確認]` の一覧
- [反省の作法](知見/反省の作法.md) — 振り返りを行動の変更につなげる手順
- [翻訳メモ](知見/翻訳メモ.md) — 翻訳で得た学び

## 置き場
| 場所 | 入れるもの | 索引 |
|---|---|---|
| `日々/` | その日のこと `YYYY-MM-DD.md` | [日々](日々/README.md) |
| `人物/` | 人のこと | [人物](人物/README.md) |
| `事業/` | 事業の数字・経緯 | [事業](事業/README.md) |
| `知見/` | 調べたこと・計算・案・反省 | [知見](知見/README.md) |
| `sources/` | 資料の要約 | [sources](sources/README.md) |
| `私事/` | 家族・体・私的なお金（ここだけに書き、他へ書き写さない） | [私事](私事/README.md) |

## 決まり
- 新しいノートは、関連ノートへのリンク5本以上と、この目録への1行を付ける
- 訂正は最優先で記録し、古い記録は上書きして「以前は〜」と残す
- 確かめるのは `python3 リンク健診.py`（終了コード 0 なら良し）
