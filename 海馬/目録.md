# 海馬 — 目録

**この保管庫の入口。何がどこにあるか、そして「新しく分かったことをどこに足すか」の表。**
**書くのは Claude、読むのは イマムラヒデタダ。** 手で直しても構わないが、正本はここ。海馬は第一に Claude の作業記憶。読みづらさを理由に削らない。

## いま `[2026-10-23]`
- 海馬が生まれた。**本人に頼むことは1枚に → [[やること]]**。本人のページは [[本人]]、目標は [[ゴール]]、止まっている用件は [[保留中のタスク]]

## 作法（スキル `kaiba`）
| 操作 | 何をするか |
|---|---|
| **ingest** | 資料を読み、`sources/` に要約を書き、関連ノートとこの目録を更新する |
| **query** | 海馬に問い、**出典つき**で答える。無いことは「無い」と言う |
| **lint** | 矛盾・古くなった記述・孤立ページ・切れたリンクを道具で見つける |
| **整理** | ①移す ②索引を作る ③リンクを足す。**削除はしない** |

## どこに何を蓄積するか
| # | 起きたこと・分かったこと | 書く場所 |
|---|---|---|
| 1 | 私的なこと（家族・体・私的なお金） | `私事/`。他へ書き写さない |
| 2 | 人について分かったこと | `人物/〈名前〉.md`（誰か／関係／強みと制約／取り決め／会った記録） |
| 3 | 事業の状態・数字・決定・経緯 | `事業/〈事業名〉.md`（現状 → 売り物 → 数字 → 体制 → 経緯 → 未確認） |
| 4 | 事業をまたいで使える学び・調べたこと | `知見/` |
| 5 | お金・口座・設備・道具・自動化・拠点 | `基盤/` |
| 6 | 読んだ資料の要約 | `sources/`（1資料1ファイル。冒頭に出典） |
| 7 | 目標・完了基準・期限 | [[ゴール]] |
| 8 | その日に起きたこと・海馬に足したもの | `日々/YYYY-MM-DD.md` |
| 9 | 毎回の判断に効く一行 | 憲法（A: 置き場の直下の `CLAUDE.md`／B: `~/.claude/CLAUDE.md`）。薄く保つ |
| 10 | 本人にしかできないこと（支払い・電話・OK） | [[やること]]。番号で答えてもらう |
| 11 | 作業中のファイル・成果物 | A: Claude のアーティファクト（リンク）か会話で渡したファイル／B: `~/Documents/汎用/〈作業フォルダ〉/`。海馬には場所だけ書く |

**迷ったら `日々/` に書いて、後で移す。** 書かないよりずっと良い。
